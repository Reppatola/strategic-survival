## 🎮 Что за игра

**Strategic Survival** — пост-апокалиптическая MMO-песочница с тактическим выживанием.

**Центральная механика — СИСТЕМА ШУМА.** Каждое действие игрока генерирует звук в **децибелах**. Шум привлекает зомби. Игрок выбирает: шуметь и рисковать или красться и ждать.

## 👁️ ВИЗУАЛЬНАЯ КОНЦЕПЦИЯ — ключевое решение

### Камера: One-Point Perspective (одноточечная перспектива)

**Как работает:**
- Камера смотрит **прямо вниз** на героя
- **Герой всегда в центре экрана**
- **В центре** — объекты выглядят **плоско** (только крышка)
- **По краям** — объекты показывают **боковые стенки** (объём)
- **Линии крыш и стен сходятся** к точке под героем

**Референс:** учебный рисунок одноточечной перспективы.

**Аналогия:** ты смотришь на мир через **широкоугольный объектив** сверху.

**Что даёт:**
- Игрок чувствует себя в **реальном 3D-мире**
- Но камера **всегда на герое** — как в Diablo
- Естественный переход плоскость → объём
- **Работает автоматически** в Three.js с PerspectiveCamera

### Стиль: Low-Poly 3D

**Все модели — простые формы:**
- Дом = 2 куба (стена + крыша)
- Дерево = цилиндр + сфера или конус
- Машина = 2 коробки
- Герой = low-poly humanoid
- Зомби = low-poly humanoid другой формы

**Материалы:**
- **Плоские цвета** (flat colors), не текстуры
- Можно использовать `MeshStandardMaterial` с `flatShading: true`
- Для стилизации — минимум градиентов

**Почему low-poly:**
- Весит мало (2-50 КБ на модель)
- Быстро рендерится
- Работает на мобильных
- Легко делать в Blender
- Уникальный стиль

## 📐 КАМЕРА — техническая реализация

```js
const camera = new THREE.PerspectiveCamera(
  60,                        // FOV — широкий, даёт эффект "рыбьего глаза" без искажений
  window.innerWidth / window.innerHeight,
  0.1,
  200
);
camera.position.set(0, 30, 0);       // строго сверху
camera.lookAt(0, 0, 0);              // смотрим на героя
```

**Ключевое:**
- FOV **55-70°** — даёт заметную перспективу
- Позиция **строго над героем** (Y — вверх, X и Z = 0 относительно героя)
- Камера **следует за героем** через `lerp` — плавно

**One-point perspective работает автоматически:** объекты на краях экрана видны **сбоку**, потому что камера смотрит на них под углом.

## 🔧 КЛЮЧЕВЫЕ ТЕХНИЧЕСКИЕ РЕШЕНИЯ

### InstancedMesh для производительности
Если 100+ деревьев — использовать `THREE.InstancedMesh`. Один draw call на все деревья.

```js
const treeMesh = new THREE.InstancedMesh(geometry, material, 100);
for (let i = 0; i < 100; i++) {
  treeMesh.setMatrixAt(i, matrix);
}
scene.add(treeMesh);
```

### Raycaster для конуса обзора зомби
```js
const raycaster = new THREE.Raycaster();
raycaster.set(zombie.position, direction);
const hits = raycaster.intersectObjects([player], true);
```

### Fog для атмосферы
```js
scene.fog = new THREE.Fog(0x1a1a1a, 30, 80);
```
Всё, что дальше 80 метров — скрыто туманом. Создаёт глубину.

### Тени (опционально)
```js
renderer.shadowMap.enabled = true;
renderer.shadowMap.type = THREE.PCFSoftShadowMap;
```
Тени — красиво, но **дорого**. Можно отключить для мобильных.
