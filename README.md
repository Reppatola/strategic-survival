## О проекте

Гибрид MMO-песочницы и тактического выживания в мире PvPvE. Центральная механика — **система Шума**: каждое действие игрока (движение, стрельба, ближний бой) генерирует звук, который привлекает внимание мира. Игрок выбирает: шуметь и рисковать или красться и ждать.

---

## Ключевые механики

- 🔊 **Двухслойная система Шума** — базовый (движение) + импульсный (выстрелы, удары). Три режима: **стелс (C)** / **ходьба (WASD)** / **бег (Shift)**.
- ⚠️ **Критический режим** — при 100% шума мир переходит в тревогу. Держится, пока шум не упадёт до 10%.
- 👁️ **Направленные стражи** — зомби с конусом обзора 90°. Смотрят в одну сторону, имеют слепые зоны.
- 🧟 **Волны на шум** — при критическом шуме каждый выстрел вызывает новую группу с края карты. Зомби идут к **последней громкой точке**.
- 🔒 **Блокировка территории** — 12 секунд непрерывной тревоги → локация закрывается. Выход только через **полную зачистку**.
- ⚔️ **Ближний бой** — удар **SPACE** рядом с врагом. **Сзади — мгновенное убийство**, тихо. Спереди — урон и шум +8%.
- 🔫 **Оружие в руках** — при выстреле герой меняет спрайт и поворачивается в сторону выстрела.

## Управление

### Клавиатура (ПК)

| Клавиша | Действие |
|---|---|
| **W A S D** | Ходьба (шум 20%) |
| **Shift + WASD** | Бег (шум 50%) |
| **C + WASD** | Красться (шум 5%) |
| **ЛКМ** | Выстрел в сторону курсора (+34% шума) |
| **SPACE** | Ближний бой (+8% шума, сзади — мгновенное убийство) |
| **R** | Рестарт после смерти |

### Тачскрин (мобильные)

| Элемент | Действие |
|---|---|
| **Левый джойстик** | Движение |
| **Правый джойстик** | Стрельба в сторону |
| **Кнопка C** | Вкл/выкл стелс |
| **Кнопка 🏃** | Вкл/выкл бег |

Мобильные контролы включаются автоматически на touch-устройствах. Для теста на ПК добавь `?touch=1` в адрес.
