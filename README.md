## О проекте

Гибрид MMO-песочницы и тактического выживания в мире PvPvE. Центральная механика — **система Шума**: каждое действие игрока (движение, стрельба, взаимодействие) генерирует звук, который привлекает внимание мира. Игрок выбирает: шуметь и рисковать или красться и ждать.

### Ключевые механики

- 🔊 **Двухслойная система Шума** — базовый (движение) + импульсный (выстрелы). Три режима передвижения: **стелс (C)** / **ходьба (WASD)** / **бег (Shift)**.
- ⚠️ **Критический режим** — при 100% шума мир переходит в тревогу. Импульсный шум затухает, критический режим держится, пока шум не упадёт до 10%.
- 👁️ **Направленные стражи** — зомби с конусом обзора 90°. Смотрят в одну сторону, имеют слепые зоны.
- 🧟 **Волны на шум** — при критическом шуме каждый выстрел вызывает новую группу с края карты. Зомби идут к **последней громкой точке**, а не к игроку.
- 🔒 **Блокировка территории** — 12 секунд непрерывной тревоги → локация закрывается. Выход только через **полную зачистку** всех зомби внутри.

## Управление

| Клавиша | Действие |
|---|---|
| **W A S D** | Ходьба (шум 20%) |
| **Shift + WASD** | Бег (шум 50%) |
| **C + WASD** | Красться (шум 5%) |
| **ЛКМ** | Выстрел в сторону курсора (+34% шума) |
| **R** | Рестарт после смерти |
